# HabershonLab Research Guide

This document is intended as a useful resource for members of the research team of Prof. Scott Habershon in the Department of Chemistry at the University of Warwick. It may also be useful for others in the field of computational chemistry.

This repo contains a simple set of Jupyter notebooks and related scripts that perform common tasks, primarily plotting graphs for publications.
