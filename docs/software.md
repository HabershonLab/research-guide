# Computational chemistry software

We use a wide range of computational chemistry tools in our research projects. This page contains a list and description of the key tools used.

## Electronic structure codes

* [ORCA](https://www.faccts.de/orca/)
  
Orca performs a very wide range of *ab initio* and semi-empirical calculations, including DFT, HF, CASSCF, MP2 and more. 

* [NWChem](https://www.nwchem-sw.org)

NWChem also contains a wide range of electronic structure calculations and methods, including both ground-state and excited-state calculation methods.

* [Psi-4](https://psicode.org)

This is an electronic structure code that has a python interface. It can be run as both a standalone package or as part of a Jupyter notebook.

* [PySCF](https://pyscf.org)

The PySCF code also has a python interface, enabling integration in Jupyter notebooks.
